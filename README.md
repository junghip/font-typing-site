# Pretendard Type Specimen

Pretendard 폰트로 텍스트를 직접 편집하며 크기/레이아웃 변화를 확인하는 타이핑 웹사이트입니다.

- 본문 텍스트를 클릭해서 직접 수정할 수 있습니다.
- 우측 상단 슬라이더로 글자 크기를 조절합니다. 글자가 작아질수록 더 많은 텍스트가, 커질수록 일부만 보입니다.
- 초기화 버튼을 누르면 크기와 텍스트가 모두 기본값으로 돌아갑니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 빌드나 서버가 필요 없습니다.

## GitHub Pages로 배포

저장소 Settings → Pages에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하면 공개 링크가 생성됩니다.
